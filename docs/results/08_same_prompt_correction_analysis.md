# 8. Same-prompt Base/CI correction analysis

The broad model-diffing results suggest that much of the machinery is shared, but some identical privacy prompts still produce opposite decisions. The final analysis asks what differs on those naturally occurring correction cases.

## Paired set

The paired PrivacyLens set contains 27 exact cases where:

```text
Base: Yes
CI:   No
```

Composition:

- 4 seed,
- 5 vignette,
- 16 trajectory,
- 2 trajectory-enhancing.

By source, the set contains 12 literature, 9 crowdsourcing, and 6 regulation cases.

These cases are not used to discover the L18 heads, L22 writers, or N13149.

## Natural checkpoint differences

On the 27 same-input cases:

| Quantity | Mean |
|---|---:|
| Base decision margin | +2.025 |
| CI decision margin | -2.940 |
| CI minus Base margin | -4.965 |
| CI minus Base N13149 activation | -6.711 |

Thus, when CI changes a Base Yes into a No on the same prompt, the behavioral correction is accompanied by a substantial downstream difference at the previously identified writer neuron.

## What this analysis does and does not say

This comparison is descriptive, not an intervention. It does not identify where the checkpoint difference first originates. The N13149 shift could be the downstream consequence of an earlier routing change, a change in processing between L18 and L22, a change in the writer-state calibration itself, or an interaction among these possibilities.

The analysis therefore narrows the remaining question rather than closing it.

For convenience, the 27 matched rows are exported directly to
`results/privacylens/same_prompt_correction_analysis.csv`, with the compact
summary in `tables/privacylens/same_prompt_correction_summary.csv`. These files
are generated by `scripts/privacylens/build_same_prompt_correction_analysis.py`
from the already saved Base and CI PrivacyLens evaluation outputs. No new
intervention is run for this analysis.
